# 更新日志

## [2.3] - 2026-11-07

作品管理与台本悬浮窗。

### 新增

- **长按编辑作品**：长按进入批量后单选一个作品，点「编辑名称」可自定义作品名（优先于
  文件夹名显示，RJ 编号退到小标题）与「收藏置顶」；详情页「编辑」弹窗同样支持。
  批量横幅新增「收藏置顶」一键收藏多个作品。
- **R18 隐藏**：设置 → 曲库与扫描 → 内容显示，默认开启，按 DLsite 识别 / 手动分级
  过滤成人向作品；主动筛选「成人」时仍会显示。
- **日期**：详情页小标题展示发售日（DLsite 识别）与收录日期（作品文件夹时间）；
  排序新增「发售日」，原「时间」明确为「添加日期」。
- **台本悬浮窗（桌面歌词）**：设置 → 台本与音频开启后，播放带时间轴的台本时
  当前句子悬浮显示在桌面上，可拖动（需授予「显示在其他应用上层」）。
- **社团 / 声优筛选**：曲库筛选行直接提供「社团」「声优」「标签」「自定义标签」
  下拉筛选（有 DLsite 数据即出现），不必再进横屏菜单。
- **悬浮窗控制条**：轻点桌面台本悬浮窗展开控制条 —— A− / A+ 调节字号
  （70%–180%，点百分比复位 100%）、一键关闭；字号写入设置持久保存，
  也可在设置 → 台本悬浮窗里用滑杆调。控制条 5 秒无操作自动收起。

### 修复

- **台本悬浮窗不显示歌词**：悬浮窗挂上后文本引用从未初始化，进度刷新被直接
  跳过，桌面上只剩一个空胶囊。现在挂窗后立即写入当前句子，无时间轴台本
  显示曲目名。
- **作品标题显示**：列表 / 卡片 / 详情页标题优先使用 DLsite 识别到的作品名
  （自定义名 > DLsite 标题 > 文件夹名），RJ 编号不再拼在标题里，
  改为标题下方一行小号浅色文字。

### 优化

- **消灭横向滑动**：曲库筛选行、批量横幅、详情页操作行 / 标签行、播放页
  内容切换、设置页主题与外观选项全部改为自动换行（FlowRow），
  功能再多也只是折行，不再需要左右滑动。
- **毛玻璃观感回调**：恢复 20dp 半径、不降采样、浅色 tint 0.72 / 深色 0.60 的
  2.2beta1 质感，滚动中也不再退回纯色；低端设备掉帧仍可用「实时毛玻璃」开关关闭。
- **动画提速**：展开/收起/迷你播放条等过渡统一改为 120–200ms 的短促 tween，
  比默认 spring 更跟手，中途掉帧也不明显。

## [2.2.2] - 2026-11-06

动画与滚动流畅度专项。

### 优化

- **滚动时暂停实时毛玻璃**：实时模糊每帧都要重新捕获身后内容再做模糊（官方基准约 +45% 帧耗时），
  滚动列表就是「每帧一次全屏捕获」。现在滚动期间磨砂栏退回半透明纯色（零 GPU 成本），
  停下约 140ms 后自动恢复毛玻璃 —— 顺滑与观感兼顾。
- **列表项不再做磁盘 IO**：封面查询此前每项都会「线性扫全库项目 + File.isFile 磁盘 stat」，
  滚动时每帧重复执行；改为项目索引 O(1) 查表 + 封面结果缓存，命中时零 IO。
- **顶部收起判定去抖**：滚动状态机只在真正跨过阈值时更新状态，不再每滚一像素写一次。
- **实时毛玻璃降本**：模糊输入降采样（HazeInputScale 0.5，官方基准省 5–20% 帧耗时）、
  模糊半径 20dp → 14dp 并稍提着色补偿观感 —— 实时模糊是全局最贵的渲染项
  （官方基准约 +45% 帧耗时），是此前掉帧的主因。
- **「实时毛玻璃」开关**：设置 → 外观 → 不透明度与模糊，可整体关闭顶栏与悬浮底栏的
  实时模糊（退回半透明纯色，零 GPU 成本）；低端设备掉帧时建议关闭。背景模糊不受影响。

## [2.2] - 2026-10-31

一次性收录自 v2.1 以来全部改动：iOS 风格玻璃界面重构、交互流畅度与易用性专项。

### 界面重构（iOS 风格）

- **透明玻璃质感**：顶栏 / 底栏 / 迷你播放条 / 卡片 / 列表行改为半透明材质，
  设置背景图或渐变时能透出底层，形成毛玻璃观感；容器用发丝描边勾边。
- **iOS 配色**：浅色为分组灰底（#F2F2F7）+ 纯白卡片 + 系统蓝（#007AFF），
  深色为纯黑底 + #1C1C1E 卡片 + #0A84FF；分隔线改用 iOS 半透明描边。
- **大圆角 + 无衬线排版**：全局圆角提升到 10–24dp，标题加粗、去掉衬线与等宽字。
- 播放按钮改为系统蓝实心圆钮；歌词当前句加大加粗。
- **高斯模糊磨砂玻璃**：顶栏与底部悬浮栏（迷你播放条 + 导航胶囊）为真正的高斯模糊
  毛玻璃（Haze 库），对身后的背景与滚动内容实时模糊再叠色；卡片 / 列表行统一为
  半透明轻玻璃 + 极淡描边（不做实时模糊以保证滚动性能）。
- **悬浮玻璃底栏**：迷你播放条 + 导航合并为一组悬浮玻璃胶囊（总高约 120dp，
  旧版约 190dp），浮在内容上方；页面从它后面穿过（能隐约看到），
  卡片之间的空隙不拦截点击，不会挡住后方作品的点按；
  播放页固定布局时自动让出底部空间。

### 交互改进

- **作品详情页一体化**：头图、标签、DLsite 信息与选集列表合并为同一个滚动流，
  往下滑自然进入选集；移除独立的「选集」按钮与全屏选集二级页，返回键始终返回曲库。
- **主页筛选随下滑隐藏**：搜索框与筛选 chips 行在列表下滑时自动收起，回顶自动展开。
- **批量模式退出入口重做**：进入批量后顶部出现醒目的横幅，「✕ 退出批量」固定在最左；
  系统返回键同样可退出；横幅内新增「全选 / 清除」，操作行横向可滚。
- **长按进入批量**：列表与卡片模式都支持长按作品直接进入批量并勾选；
  「批量」升级为筛选行的独立入口，不再藏在「年龄限制」弹窗里。
- **扫描实时进度 + 可取消**：扫描时显示「已扫 N 个目录 · 发现 N 首音频」的递增计数，
  随时可点「取消扫描」，取消后已有曲库保持不变。
- **后台任务状态拆分**：扫描 / 识别 / 写标签 / 检查更新 / 解压 / 同步已购各自独立显示进度，
  不再互相覆盖；任务卡片列出所有进行中的任务。
- **写标签自动备份**：首次改写某个音频前，原始文件自动备份到应用内部；
  设置页显示已备份数量，可一键恢复全部原始文件（恢复前有确认）。
- **视频手势 OSD**：双击快退/快进、长按 2 倍速、左侧滑动调音量、右侧滑动调亮度，
  操作时画面中央浮现半透明提示（图标 + 数值）；第一次进视频播放页弹出手势说明（只弹一次）。
- **台本匹配报告**：「台本」筛选里新增报告入口，列出所有没匹配到台本的作品，逐曲目直达「指定台本」。
- **曲库空态三分**：扫描中显示「正在扫描曲库…」转圈，不再误显「没有找到音频文件」；
  真没找到时给出原因说明与「重新选择文件夹」按钮。
- **根目录失效恢复流**：曲库目录被删 / 移动 / 权限被收回时，全屏引导「重新选择文件夹」，
  不再只弹一句 toast。
- **播放错误反馈**：文件被移动 / 删除 / 损坏导致播放失败时，明确提示原因，不再静默无反应。
- **批量分级可撤销**：批量「标为成人 / 标为全年龄」后 snackbar 上有「撤销」，可完整还原每个作品的原分级。
- **台本空态直达手动指定**：播放页没有台本时直接给「选择台本」按钮，不必再去「更多」菜单里翻。
- **台本手动滚动优先**：拖动台本时暂停自动跟随（回看前文不再被拽回），松手 2.5 秒自动恢复，
  右下角有「回到当前进度」一键恢复。
- **搜索框一键清空**：搜索词非空时出现「✕」清空按钮。
- **开启自动写入需确认**：开启「扫描后自动写入台本标签」时弹确认框，说明会修改原始音频文件。
- 应用内版本号修正：此前「关于」页一直显示 2.1，现与包版本一致。

### 修复

- **提示条不再用黑框**：扫描完成、识别结果等提示原为深色 Material 黑框，叠在玻璃栏上
  既不统一又遮挡导航；现改为与底栏同材质的磨砂玻璃胶囊，悬浮在底栏上方，不影响点击
- 竖屏「清除筛选」现在连「台本 / 年龄限制」筛选一起清除，与横屏行为一致；只设台本筛选时也有清除入口
- 曲目搜索命中超过 80 条时显示真实总数并提示「请细化关键词」，不再把截断后的 80 当总数
- 台本自动滚动改用动画滚动，跟随连续平滑，不再每 400ms「跳」一格

### 优化（性能与动画）

- 修复全局掉帧主因：播放进度状态在根部被整个界面收集，每次进度刷新（400ms）都重组整个页面——
  现在进度只在迷你条、走带、台本跟随等真正需要的地方局部生效，且状态无变化时不再发射
- 封面均衡器动画：暂停时完全停止动画循环，不再空转渲染
- 台本逐句定位改为时间轴二分查找（O(log n)），几百行的台本每次进度刷新不再全量扫描
- 纯文本台本跟随：目标位置几乎没变时不再重启动画，滚动更连贯
- **UI 动画**：标签页切换按方向滑动 + 淡入淡出过渡；迷你播放条出现 / 收起带展开 / 收合动画；
  台本「回到当前进度」按钮缩放淡入
- 曲目搜索结果按查询缓存（不重复全库过滤）；横竖屏搜索框合并为共用组件；批量操作行复用统一的标级逻辑
