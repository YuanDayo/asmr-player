# 更新日志

版本号遵循[语义化版本](https://semver.org/lang/zh-CN/)。构建产物：
`com.kiite.player-<版本号>.apk`。

## [2.2beta1] - 2026-10-31

磨砂材质返工。

### 变更

- **撤销液态玻璃渐变**：上一版的垂直渐变填充与白色轮缘描边在部分设备上出现白色条带伪影，全部撤销。
- **高斯模糊磨砂**：底部悬浮栏（迷你播放条 + 导航胶囊）与顶栏改为真正的高斯模糊毛玻璃
  （Haze 库）——对身后的背景与滚动内容做实时模糊再叠色，才是 iOS 的磨砂观感；
  修复浅色主题下两条悬浮卡显示为纯白条的问题。
- **卡片回归轻玻璃**：卡片 / 列表行恢复为半透明 + 极淡描边（描边比 2.2beta 首版更淡），
  列表卡片不做实时模糊以保证滚动性能；磨砂只用于顶栏与底部悬浮栏。

## [2.2beta] - 2026-10-31

一次性收录自 v2.1 以来全部改动：交互流畅度、易用性与 iOS 风格界面重构。

### 界面重构（iOS 风格）

- **透明玻璃质感**：顶栏 / 底栏 / 迷你播放条 / 卡片 / 列表行改为半透明材质，
  设置背景图或渐变时能透出底层，形成毛玻璃观感；容器用发丝描边勾边。
- **iOS 配色**：浅色为分组灰底（#F2F2F7）+ 纯白卡片 + 系统蓝（#007AFF），
  深色为纯黑底 + #1C1C1E 卡片 + #0A84FF；分隔线改用 iOS 半透明描边。
- **大圆角 + 无衬线排版**：全局圆角提升到 10–24dp，标题加粗、去掉衬线与等宽字。
- 播放按钮改为系统蓝实心圆钮；歌词当前句加大加粗。
- **液态玻璃描边**：卡片与栏的轮廓不再用深色发丝线「框住」，改为顶部白色高光
  渐隐到底部微暗的玻璃轮缘（浅色）与幽微白光（深色），靠光影勾轮廓。
- **全局玻璃统一**：所有卡片级容器 —— AsmrCard 卡片、曲库列表行 / 作品卡、
  播放页控制卡、顶栏、迷你播放条、悬浮导航胶囊 —— 统一改用同一套
  液态玻璃渐变填充（上亮下微暗）；修复浅色主题下底栏两条悬浮卡片
  显示成纯白条的问题。
- **悬浮玻璃底栏**：迷你播放条 + 导航合并为一组悬浮玻璃胶囊（总高约 120dp，
  旧版约 190dp），浮在内容上方；页面从它后面穿过（能隐约看到），
  卡片之间的空隙不拦截点击，不会挡住后方作品的点按；
  播放页固定布局时自动让出底部空间。

### 交互改进

- **作品详情页一体化**：头图、标签、DLsite 信息与选集列表合并为同一个滚动流，
  往下滑自然进入选集；移除独立的「选集」按钮与全屏选集二级页，返回键始终返回曲库。
- **主页筛选随下滑隐藏**：搜索框与筛选 chips 行在列表下滑时自动收起，回顶自动展开。
- **批量模式退出入口重做**：进入批量后顶部出现醒目的横幅，「✕ 退出批量」固定在最左；
  系统返回键同样可退出；横幅内新增「全选 / 清除」，操作行横向可滚。
- **长按进入批量**：列表与卡片模式都支持长按作品直接进入批量并勾选；
  「批量」升级为筛选行的独立入口，不再藏在「年龄限制」弹窗里。
- **扫描实时进度 + 可取消**：扫描时显示「已扫 N 个目录 · 发现 N 首音频」的递增计数，
  随时可点「取消扫描」，取消后已有曲库保持不变。
- **后台任务状态拆分**：扫描 / 识别 / 写标签 / 检查更新 / 解压 / 同步已购各自独立显示进度，
  不再互相覆盖；任务卡片列出所有进行中的任务。
- **写标签自动备份**：首次改写某个音频前，原始文件自动备份到应用内部；
  设置页显示已备份数量，可一键恢复全部原始文件（恢复前有确认）。
- **视频手势 OSD**：双击快退/快进、长按 2 倍速、左侧滑动调音量、右侧滑动调亮度，
  操作时画面中央浮现半透明提示（图标 + 数值）；第一次进视频播放页弹出手势说明（只弹一次）。
- **台本匹配报告**：「台本」筛选里新增报告入口，列出所有没匹配到台本的作品，逐曲目直达「指定台本」。
- **曲库空态三分**：扫描中显示「正在扫描曲库…」转圈，不再误显「没有找到音频文件」；
  真没找到时给出原因说明与「重新选择文件夹」按钮。
- **根目录失效恢复流**：曲库目录被删 / 移动 / 权限被收回时，全屏引导「重新选择文件夹」，
  不再只弹一句 toast。
- **播放错误反馈**：文件被移动 / 删除 / 损坏导致播放失败时，明确提示原因，不再静默无反应。
- **批量分级可撤销**：批量「标为成人 / 标为全年龄」后 snackbar 上有「撤销」，可完整还原每个作品的原分级。
- **台本空态直达手动指定**：播放页没有台本时直接给「选择台本」按钮，不必再去「更多」菜单里翻。
- **台本手动滚动优先**：拖动台本时暂停自动跟随（回看前文不再被拽回），松手 2.5 秒自动恢复，
  右下角有「回到当前进度」一键恢复。
- **搜索框一键清空**：搜索词非空时出现「✕」清空按钮。
- **开启自动写入需确认**：开启「扫描后自动写入台本标签」时弹确认框，说明会修改原始音频文件。
- 应用内版本号修正：此前「关于」页一直显示 2.1，现与包版本一致（2.2beta）。

### 修复

- 竖屏「清除筛选」现在连「台本 / 年龄限制」筛选一起清除，与横屏行为一致；只设台本筛选时也有清除入口
- 曲目搜索命中超过 80 条时显示真实总数并提示「请细化关键词」，不再把截断后的 80 当总数
- 台本自动滚动改用动画滚动，跟随连续平滑，不再每 400ms「跳」一格

### 优化（性能与动画）

- 修复全局掉帧主因：播放进度状态在根部被整个界面收集，每次进度刷新（400ms）都重组整个页面——
  现在进度只在迷你条、走带、台本跟随等真正需要的地方局部生效，且状态无变化时不再发射
- 封面均衡器动画：暂停时完全停止动画循环，不再空转渲染
- 台本逐句定位改为时间轴二分查找（O(log n)），几百行的台本每次进度刷新不再全量扫描
- 纯文本台本跟随：目标位置几乎没变时不再重启动画，滚动更连贯
- **UI 动画**：标签页切换按方向滑动 + 淡入淡出过渡；迷你播放条出现 / 收起带展开 / 收合动画；
  台本「回到当前进度」按钮缩放淡入
- 曲目搜索结果按查询缓存（不重复全库过滤）；横竖屏搜索框合并为共用组件；批量操作行复用统一的标级逻辑
