# 更新日志

本项目的版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)：`主版本.次版本.修订号`。
构建产物固定命名为 `com.asmrplayer-<版本号>.apk`。

## [1.3.1] - 2026-10-06

### 修复
- **应用从未声明 INTERNET 权限**，导致 DLsite 元数据抓取与内置登录 WebView 全部失败
  （WebView 报 `net::ERR_CACHE_MISS`）。已补上 INTERNET 与 ACCESS_NETWORK_STATE。

## [1.3] - 2026-10-06

### 新增
- **播放倍数**：播放页可选 0.5× 到 3.0×（9 档），带勾选标记，持久化保存。
- **压缩包自动识别**：扫描时识别 zip / rar / 7z / tar / gz 等；项目列表显示「含压缩包 N 个」，
  zip 可一键解压到同级「<名字>_解压」文件夹并自动重扫，rar/7z 只做提示（无原生解压支持）。
- **DLsite 接入**：按 RJ / VJ / BJ 编号抓取 DLsite 公开作品页信息（标题 / 社团 / 封面 / 发售日 / 标签），
  本地缓存、项目详情页一键识别。不涉及账号登录，只读公开页面。
- **应用内更新日志**：设置 → 关于 →「更新日志」；版本升级后首次启动自动弹一次。
- **主题色变换**：8 种强调色（跟随皮肤 / 琥珀黄 / 海蓝 / 薄荷绿 / 樱粉 / 葡萄紫 / 珊瑚橙 / 青柠）。
- **「明快」皮肤**：按设计范例重构的纸白 / 墨黑 / 功能黄风格——2px 墨黑描边、大圆角、
  右下硬投影、悬浮胶囊底栏与黄色选中态。设为默认皮肤，原有四套皮肤保留可随时切回。

### 变更
- 默认主题模式改为「浅色」以配合「明快」皮肤，仍可切回跟随系统 / 深色。
- **背景遮罩浓度可调**（0–0.95）；曲库列表与曲目行改为半透明圆角卡片，
  背景图可见但仍逐条可辨（此前背景被整片遮罩压住）。

### 修复
- 台本手动指定的重算流程会丢弃压缩包列表，导致「含压缩包」计数恒为 0。

## [1.2] - 2026-10-05

### 新增
- 支持 **WebVTT（`.vtt`）** 字幕台本，逐句高亮同步。支持 `hh:mm:ss.mmm` 与省略小时的 `mm:ss.mmm`，
  自动忽略 `NOTE` / `STYLE` / `REGION` 块以及 `<v>` `<c>` 等行内标签。
- 纯文本台本（txt / md / docx / pdf）支持行首时间标注（`[00:12]`、`00:12：`、`1:02:03 -`），
  自动识别成时间轴并与音频对齐。
- UI 改版：贴近 HyperOS 的圆角风格——悬浮胶囊底栏（选中项带胶囊指示）、大圆角卡片、圆角迷你播放条、加粗大标题。
- 版本号集中到 `appVersionName` / `appVersionCode` 两个变量，产物名自动带版本号。

### 修复
- **深色模式下纯文本台本看不见文字**：`LocalContentColor` 未被设置时默认黑色，深色底上等于隐形。
- **选择背景图报错且不生效**：系统选择器返回的 `content://` Uri 无法还原成本地路径，
  改为直接复制进应用内部存储并校验可解码；台本选择器同样加了兜底。

### 变更
- 构建产物文件名由 `app-debug.apk` 改为 `com.asmrplayer-1.2.apk`（包名 + 版本号）。
- `versionCode` 2 → 3。

## [1.1] - 2026-10-05

### 新增
- **自动识别总项目**：按曲库根目录第一级子目录归并作品，识别 RJ/VJ/BJ 作品编号，项目内按子文件夹切章节。
- **台本自动匹配**（六档）：同名 → 同编号 → 父子目录 → 同一总项目的不同子文件夹 → 整项目共用 → 名称相似。
- **手动指定台本**：可从任意目录挑台本覆盖自动匹配，持久保存、可随时清除回落。
- **专辑封面**：文件夹封面（cover / folder / 最大图片）+ 音频内嵌封面（MP3 APIC / FLAC PICTURE / M4A covr）。
- **播放列表**：播放页列出当前总项目全部音频（跨章节、跨格式统合），点击跳播。
- **皮肤自定义**：4 套配色 × 深色三态（跟随系统 / 浅色 / 深色）× 5 种背景预设 + 自定义背景图。
- **UI 卡不透明度与背景模糊**可调。
- **播放页两套布局**（大封面 / 紧凑）随时切换。
- **播放通知**点击回到应用。
- 文件 / 文件夹选择器支持「用其他应用打开」（SAF）。
- 设置页「关于」：作者、开源页、B 站主页。

### 修复
- 台本与音频位于**同一总项目的不同子文件夹**时（`音频/` 与 `台本/` 并列）无法匹配。

## [1.0] - 初始版本

- 自动识别总项目与台本、台本随播、把台本写入音频标签、Media3 后台播放、简洁三标签页界面。
- 说明：该版本没有单独打标签，代码已包含在 v1.1 中。
