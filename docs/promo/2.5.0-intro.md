## 中文案（GitHub Release 引言 / 应用商店简介，约 320 字）

Kiite Player 是一个面向本地音声收藏的 Android 播放器。你只需要指定一个放着解压作品的目录，
它会把每个文件夹自动识别成一部「总项目」：散落在 `mp3/`、`wav/`、`SE/`、`台本/` 里的内容
统合到一起，标题里带上 RJ / VJ / BJ 编号，章节与跨格式音频一并整理好。

台本是它的重点：LRC / SRT / VTT / ASS / PDF / docx 六档自动匹配，带时间轴的逐句高亮、
自动滚动、点句跳转，没有时间轴也能按行首时间识别；时间轴不准可以自己校准，也能写进音频标签。

v2.5.0 补齐了三块能力：**EQ 与音频增强**（五段均衡、低音、环绕、响度，只改输出不改源文件）、
**DLsite 深度集成**（识别标题 / 社团 / 封面 / 声优，同步已购作品，站内搜索直达下载）、
以及**接入 asmr.one**——在线搜索免费作品后，直接在选择页挑文件、原生下载落盘到曲库。

开源免费、无需注册、数据留在本地。

## 长文案（功能分点，适合公众号 / 论坛长贴）

### 一、先把曲库理干净

- **自动识别总项目**：递归扫描根目录，按第一级子目录归并作品，识别 RJ / VJ / BJ 编号写在标题里；
  项目内再按子文件夹切分章节，全部音频统合展示，不再「一首一首翻」。
- **六档台本匹配**：同名 → 同编号 → 父子目录 → 同项目的不同子文件夹 → 整项目共用 → 名称相似；
  匹配不理想可手动指定，随时清除回落自动匹配。
- **作品体检**：空作品、可疑小文件（下载截断）、跨作品同名、疑似重复（同名同大小）一次报出来。

### 二、听的时候，台本跟着走

- 逐句高亮 + 自动滚动 + 点句跳转；行高、字体（默认 / 衬线 / 等宽）、阅读主题（跟随 / 纸张 / 夜读）可调。
- 时间轴不准？A/B 点定句首句尾，或整体平移，**只存应用私有数据，绝不回写你的台本文件**。
- 睡眠定时（倒计时 / 播完本章停 / 播完本作品停，带渐停）、A-B 循环、书签、播放历史与续播点。

### 三、声音本身也能调

- 五段均衡（60Hz–10kHz）+ 低音增强 + 环绕声 + 响度增益；
- 六种预设：原声 / 人声清晰 / 低语增强 / 温暖 / 低音质感 / 明亮通透，也可自定义；
- 只作用于播放输出流，**不修改源文件**；总开关关闭即完全释放，输出与未开音效一致。

### 四、专辑信息与下载，不用来回切浏览器

- **DLsite**：按 RJ 号识别标题 / 社团 / 封面 / 声优 / 标签，封面自动作为专辑封面；
  支持账号登录、已购作品同步（首页直接显示「已购未下载」）、站内搜索直达下载页、批量识别整个曲库。
- **asmr.one**：搜索免费作品，点「下载」进入文件选择页——树形勾选具体文件，文件夹勾选框作用于整个子树，
  「推荐音频」默认勾好（同目录 mp3 > wav > flac 去重，不会重复下三份）；
  下载走原生 API，可随时取消、token 失效自动重登，保持站内目录结构落到 `曲库根/{RJ 编号 标题}/`，完成后自动重扫。

### 五、该有的都有

后台播放（Media3）、通知 / 锁屏控制、视频与图片查看、桌面歌词、
4 套配色 × 深色三态 × 背景预设、智能收藏、系列管理、全局侧滑返回。
开源免费、无需注册、数据全在本地。
